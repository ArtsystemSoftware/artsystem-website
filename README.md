# ArtSystem - Site Institucional

Este é o repositório do site institucional da ArtSystem, uma empresa especializada em soluções tecnológicas para gestão empresarial. O site foi desenvolvido utilizando Next.js e React, com o objetivo de apresentar os serviços e produtos oferecidos pela ArtSystem, além de fornecer informações de contato e depoimentos de clientes.

## Tecnologias Utilizadas

- **Next.js**: Framework React para desenvolvimento de aplicações web.
- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática ao código.
- **Tailwind CSS**: Framework CSS para estilização rápida e eficiente.
- **Swiper**: Biblioteca para criação de carrosséis e sliders.
- **React Icons**: Conjunto de ícones para React.

## Estrutura do Projeto

- **components**: Contém os componentes reutilizáveis utilizados no site, como `Container`, `Benefits`, `Testimonials`, etc.
- **pages**: Contém as páginas do site, como a página de contato (`contato`) e outras páginas institucionais.
- **public**: Contém os arquivos estáticos, como imagens e ícones.
- **styles**: Contém os arquivos de estilização global.
- **types**: Contém as definições de tipos TypeScript utilizados no projeto.

## Funcionalidades

- **Página Inicial**: Apresenta uma visão geral dos serviços e produtos oferecidos pela ArtSystem.
- **Depoimentos**: Seção com depoimentos de clientes satisfeitos com as soluções da ArtSystem.
- **Benefícios**: Seção destacando os principais benefícios dos produtos e serviços oferecidos.
- **Contato**: Página com informações de contato e um formulário para envio de mensagens.
